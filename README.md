# SUNTEX PIECE GOODS CO., LTD. - Professional Website

## Overview
This is a professional, responsive website for **SUNTEX PIECE GOODS CO., LTD.**, a leading textile import and export company. The website showcases the company's products, services, and provides seamless contact capabilities.

## 🌟 Features

### Core Sections
- **Home** - Eye-catching hero section with company introduction
- **About Us** - Company overview with key features and strengths
- **Products** - Comprehensive showcase of textile offerings
- **Services** - Import, export, and consulting services
- **Contact** - Interactive contact form and company information

### Design Features
✅ **Fully Responsive** - Works perfectly on desktop, tablet, and mobile devices  
✅ **Professional Branding** - Navy blue and amber color scheme  
✅ **Smooth Navigation** - Sticky navbar with active link indicators

## 🔄 How to Customize

### Change Company Information
Edit `index.html`:
- Update company name in navbar
- Modify product offerings in Products section
- Update services listed in Services section
- Add your contact details in Contact section

### Modify Colors
Edit `styles.css` - Update the CSS variables:
```css
:root {
    --primary-color: #1e3a8a;      /* Change primary color */
    --secondary-color: #f59e0b;    /* Change accent color */
}
```

### Add More Products
In `index.html`, duplicate a `.product-card` div:
```html
<div class="product-card">
    <h3>Your Product Name</h3>
    <p>Your product description here</p>
</div>
```

## 📧 Contact Form Integration
To send emails, integrate with a backend service like:
- EmailJS
- Formspree
- SendGrid
- Custom PHP/Node.js backend

Update the form submission handler in `script.js`.
